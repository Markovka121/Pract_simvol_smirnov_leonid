## 1. Что нужно уметь после задания

1. Создать файл `.py` и запустить его.
2. Вывести текст и рисунок через `print()`.
3. Понимать, зачем нужны спецсимволы `\n`, `\t`, `\\`, `\'`, `\"`.

Циклы, функции и списки **не нужны**. Только `print` и строки.

---

## 2. Мини-теория: как Python печатает картинку

`print()` выводит то, что написано в кавычках.

```python
print("Привет")
```

Если написать несколько `print` подряд — каждый начнётся с новой строки:

```python
print(" /\\_/\\ ")
print("( o.o )")
print(" > ^ < ")
```

Можно нарисовать всё в одном `print`, если внутри строки поставить перенос `\n`.

---

## 3. Специальные символы (обязательно выучить)

Внутри строки некоторые комбинации имеют особое значение. Они начинаются с обратного слэша `\`.

| Символ | Название | Что делает | Пример в коде | Что увидит ученик |
|--------|----------|------------|---------------|-------------------|
| `\n` | новая строка (newline) | переносит курсор на следующую строку | `print("раз\nдва")` | раз<br>два |
| `\t` | табуляция (tab) | делает большой отступ, как клавиша Tab | `print("кот\tмяу")` | кот　　мяу |
| `\\` | сам слэш | печатает один знак `\` | `print("C:\\Python")` | C:\Python |
| `\'` | кавычка | печатает одинарную кавычку внутри `'...'` | `print('это \'кот\'')` | это 'кот' |
| `\"` | кавычка | печатает двойную кавычку внутри `"..."` | `print("это \"кот\"")` | это "кот" |
| `\r` | возврат каретки | возвращает курсор в начало строки (редко нужно новичкам) | — | — |
| `\b` | backspace | стирает предыдущий символ (редко) | — | — |

### Важные правила для рисунков

1. Чтобы нарисовать `\`, в строке пишем `\\`.
2. Чтобы кавычка не сломала строку, экранируем её: `\"` или `\'`.
3. Пробелы тоже рисуют. Если убрать пробел — ушки кота съедут.
4. Лучше использовать **моноширинный шрифт** в терминале (уже так и есть). Тогда колонки ровные.

### Набор символов, из которых удобно рисовать

```
 .  ,  '  `  "  :  ;  !  ?  *  +  -  =  ~  ^
 /  \  |  _  (  )  [  ]  {  }  <  >
 @  #  $  %  &
 ▲ ▼ ● ○ ■ □ ★ ☆ ♥ ❤ ฅ ^ ω
```

Не все «красивые» символы одинаково выглядят в Windows / Linux / онлайн-компиляторе. Для сдачи безопаснее использовать обычные ASCII:

```
/\ _ | ( ) o . ^ < > = ~ * @
```

## 7. Частые ошибки

| Ошибка | Почему | Как исправить |
|--------|--------|----------------|
| `SyntaxError: EOL while scanning string literal` | забыли закрыть кавычку или написали `\` в конце строки | закрыть кавычку; `\` писать как `\\` |
| ушки кота кривые | разное число пробелов | копировать пробелы один в один |
| виден текст `\n`, а не перенос | написали `\\n` или обычный слэш `/n` | нужен именно `\n` |
| кот разъехался в Блокноте | не моноширинный шрифт | смотреть результат в терминале / VS Code |
| `print /\_/\` без кавычек | `print` печатает только строку в кавычках | `print("/\\_/\\")` |
